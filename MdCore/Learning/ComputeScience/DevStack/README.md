# DevStack

This will be a structured learning and professional reference for the development stack, combining theoretical foundations with practical engineering knowledge. It is intended to serve three purposes:

1. **Learn:** Understand how each technology works internally, including its underlying principles and design decisions.
2. **Apply:** Write practical, maintainable, secure, and performant software using modern engineering practices.
3. **Recall:** Quickly revisit important concepts, standard libraries, tools, terminology, and common implementation patterns.

The material will distinguish between language specifications, standard libraries, platform APIs, and third-party ecosystem tools. This is important because knowing a language and knowing its ecosystem are separate skills.

## **1. Documentation structure**

The documentation will have three levels of depth.

Level 1 — Deep technical reference

**Core technologies**

C and Embedded C · Rust · Python · PostgreSQL · Redis · HTML5 · CSS3 · TypeScript · Git · Linux

Foundations, internals, concepts, standard libraries, practical code, architecture, security, performance, testing, tooling, and best practices.

Level 2 — Ecosystem reference

**Frameworks, libraries, platforms, and engineering tools**

Django, Django REST Framework, Flask, Node.js, Angular, OpenAPI, Swagger, SQLite, scientific Python, PyTorch, ROS2, AWS, Google Cloud, Docker, Nginx, and others.

Purpose, architecture, primary concepts, common workflows, typical applications, and how each relates to the core technologies.

Level 3 — Quick recall

**Reference sheets and cross-technology knowledge**

Terminology, comparisons, command references, design principles, common pitfalls, decision guides, and revision checklists.

A compact companion to the more detailed chapters.
