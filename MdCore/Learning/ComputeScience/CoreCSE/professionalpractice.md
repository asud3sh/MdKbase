
# 30 · PROFESSIONAL PRACTICE

## 30.1 Ethics

### Ethics

**Codes:** ACM Code of Ethics, IEEE Code of Ethics.

**Principles:** Contribute to society, avoid harm, be honest, respect privacy, honor confidentiality.

**Topics:** Bias, privacy, dual use, autonomous weapons, surveillance.

**Recall:** *Do no harm.*

### Open Source

**Licenses:**
- **Permissive:** MIT, Apache, BSD
- **Copyleft:** GPL, AGPL
- **Weak copyleft:** LGPL, MPL

**Governance:** BDFL, meritocracy, foundation.

**Contribution:** Fork, branch, commit, PR, review, merge.

**Recall:** *Public code.*

### Licensing

**Permissive vs copyleft:** Permissive allows proprietary use; copyleft requires sharing.

**Compatibility:** Some licenses incompatible.

**Recall:** *Legal terms of use.*

### Intellectual Property

**Types:** Copyright, patents, trademarks, trade secrets.

**Software:** Copyright protects code; patents protect methods.

**Recall:** *Ownership of ideas.*

### Privacy Law

**GDPR:** EU; data protection, consent, right to erasure.

**CCPA:** California; consumer privacy.

**HIPAA:** US; health data.

**Recall:** *Legal data protection.*

## 30.2 Communication

### Communication

**Skills:** Writing, speaking, listening.

**Audience:** Adjust for technical level.

**Clarity:** Simple, concise, structured.

**Recall:** *Convey clearly.*

### Technical Writing

**Types:** Docs, RFCs, blog posts, tutorials.

**Principles:** Clarity > cleverness; audience-first; structured.

**Tools:** Markdown, AsciiDoc, Sphinx.

**Recall:** *Write to be understood.*

### Design Docs

**Structure:** Problem, goals, proposal, alternatives, trade-offs, risks.

**Purpose:** Think before coding; get feedback.

**Recall:** *Think before coding.*
