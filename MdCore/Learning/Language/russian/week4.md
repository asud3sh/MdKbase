# Why the Accusative Matters

In English:

> I read **a book**.

The noun "book" does not visibly change.

Russian often marks the object of an action by changing the noun.

Compare:

**Это книга.**
This is a book.

**Я читаю книгу.**
I read a book.

The noun changes:

> книга → книгу

This is the beginning of understanding Russian cases.

---

# Case Concept

Russian cases are grammatical forms that show how a noun functions in a sentence.

For example:

> Я вижу друга.

"I see a friend."

**друга** is the object of **вижу**.

You do not need to master all six Russian cases now.

For Week 4, focus on one:

> **Винительный падеж — Accusative**

Think:

**Who/what is receiving the action?**

# 2. The Basic Rule

Many feminine nouns ending in:

**-а**

change to:

**-у**

in the accusative singular.

Examples:

| Nominative | Accusative | Meaning  |
| ---------- | ---------- | -------- |
| книга      | книгу      | book     |
| сестра     | сестру     | sister   |
| мама       | маму       | mother   |
| мантра     | мантру     | mantra   |
| семья      | семью      | family   |
| практика   | практику   | practice |

# Day 2 — Accusative: Masculine Nouns

## 1. Learning Objectives

Today you will learn:

* masculine animate accusative

---

# 2. The Important Distinction

For many masculine nouns:

### Inanimate

The accusative often looks like the nominative.

**Я читаю текст.**

I read the text.

**текст → текст**

No visible change.

### Animate

The accusative often looks like the genitive.

**Я вижу друга.**

I see a friend.

**друг → друга**

---

# 3. Compare

| Nominative | Accusative | Meaning |
| ---------- | ---------- | ------- |
| храм       | храм       | temple  |
| друг       | друга      | friend  |
| брат       | брата      | brother |
| студент    | студента   | student |
| человек    | человека   | person  |
| Кришна     | Кришну     | Krishna |

Notice:

**храм** is inanimate.

**друг** is animate.

Therefore:

> Я вижу храм.

but:

> Я вижу друга.

**добрый друг**

**доброго друга**

* новый студент → нового студента

* одиннадцать

* тринадцать
* четырнадцать
* пятнадцать

# 3. Counting Practice

Then:

Then backwards:

Finally, randomly:

> 7, 14, 2, 19, 11, 5, 16, 3, 20

This develops number recognition rather than memorization in sequence.

# 4. Age

Russian expresses age using:

**Мне ... лет.**

Literally:

> To me ... years.

Natural English:

> I am ... years old.

Examples:

**Мне двадцать лет.**

I am twenty.

**Мне тридцать лет.**

I am thirty.

You will later learn the grammatical variation after different numbers.

For now, use:

**Мне ... лет.**

---

# 5. Asking Someone's Age

**Сколько тебе лет?**

How old are you?

Formal:

**Сколько вам лет?**

How old are you?

Answer:

**Мне двадцать пять лет.**

I am 25.

# 6. Quantity Questions

**Сколько?**

How many? / How much?

Examples:

* Сколько книг?
* Сколько друзей?
* Сколько людей?
* Сколько студентов?

This word will become extremely important.

# 5. Temple/Prasādam Context

A simple hypothetical dialogue:

**— Сколько стоит прасадам?**

**— Сто рублей.**

**— Дайте, пожалуйста, два.**

**— Пожалуйста.**

You're welcome / Here you are.

The point is practical Russian conversation.

# Day 5 — Dates and Basic Time Expressions

## 1. Days of the Week

| Russian     | English   |
| ----------- | --------- |
| понедельник | Monday    |
| вторник     | Tuesday   |
| среда       | Wednesday |
| четверг     | Thursday  |
| пятница     | Friday    |
| суббота     | Saturday  |
| воскресенье | Sunday    |

Notice:

**воскресенье**

literally relates historically to "resurrection" and is the Russian word for Sunday.

Do not worry about etymology at A1 level; simply learn it as the day name.

---

# 2. Today / Tomorrow / Yesterday

| Russian | Meaning        |
| ------- | -------------- |
| сегодня | today          |
| завтра  | tomorrow       |
| вчера   | yesterday      |
| сейчас  | now            |
| утром   | in the morning |
| днём    | during the day |
| вечером | in the evening |
| ночью   | at night       |

Examples:

**Сегодня понедельник.**

Today is Monday.

**Сегодня воскресенье.**

Today is Sunday.

**Завтра вторник.**

Tomorrow is Tuesday.

**Вчера была суббота.**

Yesterday was Saturday.

The final sentence introduces past tense; full past-tense grammar comes later.

---

# 3. Basic Time

**Который час?**

What time is it?

**Сейчас три часа.**

It is three o'clock.

At this stage, focus on understanding the question and common whole-hour expressions.

Today.

**Завтра.**

Tomorrow.

**В воскресенье.**

On Sunday.

**Вечером.**

In the evening.

**Когда киртан?**

**Сегодня вечером.**

This evening.

# Day 6 — Month 1 Integration

Today you will combine everything learned in Weeks 1–4.

You should now be able to create much more complete Russian sentences.

---

# 1. Core Sentence Transformation

Start with:

**Это книга.**

This is a book.

Add possession:

**Это моя книга.**

This is my book.

Add adjective:

**Это моя новая книга.**

This is my new book.

Make it an object:

**Я читаю мою новую книгу.**

I am reading my new book.

Add time:

**Сегодня я читаю мою новую книгу.**

Today I am reading my new book.

You have just combined:

* demonstrative
* possessive
* gender
* adjective agreement
* accusative
* present tense
* time expression

This is exactly the kind of cumulative learning we want.

---

# 2. Another Transformation

Start:

**Это храм.**

This is a temple.

Possessive:

**Это наш храм.**

This is our temple.

Adjective:

**Это наш большой храм.**

This is our big temple.

Action:

**Я посещаю наш большой храм.**

I visit our big temple.

Time:

**В воскресенье я посещаю наш большой храм.**

On Sunday I visit our big temple.

---

# 3. Devotional Transformation

Start:

**Это мантра.**

This is a mantra.

Possessive:

**Это моя мантра.**

This is my mantra.

Adjective:

**Это моя духовная мантра.**

This is my spiritual mantra.

Action:

**Я повторяю мою духовную мантру.**

I repeat my spiritual mantra.

Time:

**Утром я повторяю мою духовную мантру.**

In the morning I repeat my spiritual mantra.

---

# 4. People

Start:

**Это друг.**

This is a friend.

Possessive:

**Это мой друг.**

This is my friend.

Adjective:

**Это мой хороший друг.**

This is my good friend.

Object:

**Я вижу моего хорошего друга.**

I see my good friend.

Plural:

**Это мои хорошие друзья.**

These are my good friends.

Notice that you are now beginning to encounter more complex accusative forms.
